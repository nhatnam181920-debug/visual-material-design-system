# 视觉物料设计系统

> 一套可复制、可验收的视觉物料生产系统。每个模块都是「拿来就能用」的设计系统 + 模板 + 验收脚本，Agent 读一次就能产出同等或更高质量。

## 模块

| 模块 | 内容 | 状态 |
|---|---|---|
| [视觉物料设计系统-ppt（html版）](<视觉物料设计系统-ppt（html版）/README.md>) | 四套 16:9 HTML 演示设计系统（Glass Neon / 8-Bit Orbit / Swiss Modern / Editorial Serif）+ 动效组件库 + 排版规格 + 提示词库 + 打包与验收脚本 | ✅ 可用 |

## Agent 怎么用

1. 读本仓库 → 找到需要的模块（上面表格）
2. 读模块里的 `SKILL.md`（工作流 + 硬性契约 + 常见错误）
3. 读对应风格的 `DESIGN.md`（令牌 / 组件 / Do-Don't）
4. 复制 `template.html` → 只改内容 → 跑 `scripts/` 里的打包与验收

## 当前可用的模块能力

- **PPT（HTML 版）**：16:9 演示稿，单文件离线、键盘翻页、可打印 PDF；两套成熟风格，模板覆盖全部组件；验收脚本自动检查溢出/平衡/字体/媒体/外链。

## 后续模块（规划）

- 海报 / 信息图设计系统
- 短视频封面与字幕样式系统
