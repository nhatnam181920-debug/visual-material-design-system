# 设计提示词库（10 个场景）

> 这一层解决的是 MotionSites 文章里说的核心痛点：**「AI 写的业务逻辑很强，但审美很灾难」**。
> 用法：把提示词 + 你的内容一起丢给 AI，它就会按本仓库的设计系统干活，而不是给你一个 Bootstrap 风格页面。
> 每条提示词都绑定了仓库里的具体文件和硬约束，不是泛泛的「请设计得高级一点」。

---

## 00 · 通用骨架（任何场景都能加在前面）

```
请按 D:\视觉物料设计系统 的设计系统工作。

第一步：读 视觉物料设计系统-ppt（html版）/SKILL.md，按任务路由选风格。
第二步：读该风格的 DESIGN.md 与 排版规格.md，严格遵循其中的令牌、字号阶梯、
        对比度（≥4.5:1）、8px 基线网格、留白下限。
第三步：读该风格的 template.html 作为组件来源，不要自创组件。
第四步：只改内容，不改令牌与结构；需要动效时从 motion-kit.md 选，一页 ≤2 种。
第五步：交付前过一遍 排版规格.md 第 9 节自检清单。

硬边界：不虚构数据与案例；中文在字体栈前部；禁圆角+阴影同用；
        必须保留 prefers-reduced-motion 降级。
```

## 01 · 做一版 16:9 路演幻灯片

```
我要做一版 16:9 路演稿，主题：<主题>，听众：<谁>，时长：<几分钟>，页数：<N>。

按 SKILL.md 的风格选择口诀定风格（要稳选 swiss-modern，要记忆点选 8bit-orbit，
要高级可信选 glass-neon，要讲故事选 editorial-serif）。

然后复制该风格 template.html，按内容改写：
- 第 2 页就给结果或核心数字，不要铺垫
- 一页一个信息点，标题即结论
- 数字必须带来源；没有来源的不写
- 涉及效果的一律标「不承诺」
- 每页都写 <template data-notes> 讲稿，标秒数，总时长对齐我给的分钟数

交付：单文件 HTML + 逐页讲稿（md）。
```

## 02 · 把现有网页改造成我们的设计系统

```
这是现有页面：<粘贴 HTML 或文件路径>。

不要重写，做「设计系统移植」：
1. 抽取它的内容结构与文案，原样保留
2. 按 <风格名> 的 DESIGN.md 替换视觉层：颜色令牌、字体栈、字号阶梯、间距（8px 倍数）
3. 把它的组件映射到该风格 template.html 里的既有组件
4. 补 prefers-reduced-motion；动效从 motion-kit.md 选，≤2 种
5. 输出改造前后的差异清单（改了什么、为什么）

硬约束：内容一字不改（除非有事实错误）；不许删信息；不许加虚构内容。
```

## 03 · 做小红书卡片 / 社交分享图

```
把下面这段内容做成小红书卡片（3:4，1242×1660）：
<内容>

要求：
- 用 swiss-modern 的设计语言（克制、网格、单一强调色）
- 主标题 ≤14 字，一眼能读完
- 一卡一个信息点；数字要大（≥96px）
- 8px 基线网格；对比度 ≥4.5:1
- 不要堆emoji，不要渐变文字正文
- 输出：单文件 HTML（可直接截图导出）
```

## 04 · 做产品落地页首屏（Hero）

```
给我的产品 <一句话介绍> 做一个落地页首屏。

参考 motion-kit.md 的「渐变描边卡 / 流光文字 / 网格背景」，
风格用 <风格名>。

首屏必须回答三件事（缺一不可）：
1. 这是什么（一句话，≤20 字）
2. 给谁用（具体人群，不是「所有人」）
3. 下一步做什么（一个按钮 + 一句说明）

标题字号按该风格 L1；副标题 L5；CTA 用实心底 + 高对比文字。
不要放无关的装饰动效——首屏只允许一个氛围层。
```

## 05 · 给数据页做图表

```
把这组数据做成幻灯片里的图表页：
<数据>

规则（来自 排版规格.md）：
- 3–4 个关键数字用「大数字卡」，不用饼图
- 需要趋势才用折线；需要对比才用条形（横向，不用纵向）
- 条形图：标签在左、数值在右、条形零起点
- 每个数字必须带来源与口径
- 图表区占版面 ≤60%，留出金句位
- 动画只做「条形生长」或「数字滚动」，0.9–1.1s
```

## 06 · 把长文改造成可读页面

```
把下面这篇长文改造成可读的网页版：
<长文>

要求：
- 用 editorial-serif 的设计语言（衬线标题 + 无衬线正文）
- 行长 20–40 字/行；行高 1.75；段间距 ≥24px
- 标题层级 ≤4 级；每级字号按规格表 L1–L6
- 引用块用左 2px 赭红线 + 纸白加深底
- 不要分栏除非是「主+辅」；不要侧边栏
- 输出单文件 HTML，含目录锚点
```

## 07 · 统一多个页面的视觉（设计系统审计）

```
这些页面:<文件列表>。

做一次设计系统审计，输出表格：
| 页面 | 用了什么颜色 | 用了什么字体 | 字号层级 | 间距是否 8px 倍数 | 违反的规格条目 |
然后按 <风格名> 的 DESIGN.md 给出统一方案，逐页改造。

重点查：颜色是否超出令牌表、字号是否超过 6 级、有没有圆角+阴影同用、
       正文对比度是否 <4.5:1、有没有缺失 prefers-reduced-motion。
```

## 08 · 做演讲者讲稿

```
这是 <N> 页幻灯片：<文件>。

为每页写讲稿，要求：
- 每页标秒数，总时长 = <目标分钟>
- 前 90 秒必须是痛点共鸣，不要介绍产品
- 每页讲稿只讲「因果」，不念页面上的字
- 给三个「拉回注意力」的锚点句
- 标出哪里该停顿（1.5 秒）
- 结尾给一句能被记住的金句
```

## 09 · 做视频封面 / 缩略图

```
给这条视频做封面（16:9，1920×1080）：
标题：<标题>
内容：<一句话>

规则：
- 主标题 ≤12 字，900 字重 + 硬边阴影（8bit）或大字号（swiss）
- 强调色只用一个；不要三种颜色打架
- 留白 ≥30%；不要在封面上堆信息
- 底部留 17% 安全区（避开平台 UI 遮挡）
- 输出单文件 HTML，可直接截图导出 PNG
```

## 10 · 复盘一次设计改造

```
我按设计系统改造了 <页面>，这是改造前后的截图/文件。

请按 SKILL.md 的验收标准复盘：
1. 跑 qa-deck.cjs 或等价的溢出/平衡/对比度检查
2. 对照 排版规格.md 第 9 节自检清单逐项打分
3. 列出「改了但没改到点子上」的三处
4. 给出下一轮唯一最该改的一件事

不要泛泛说「整体不错」，每条都要能执行。
```

---

## 使用提示

1. **每条都能单独用**，但建议先跑 00 通用骨架
2. `<尖括号>` 里换成你的真实信息，别留着占位符
3. 提示词是**约束**，不是许愿——写清楚「不要什么」比「要什么」更有效
4. 如果 AI 产出还是「AI 味」，把 [排版规格.md](排版规格.md) 第 8 节禁用清单整段贴给它
