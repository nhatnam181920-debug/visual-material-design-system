# 排版规格库（Typography & Layout Spec）

> 这些是**硬约束**，不是建议。每套风格的 DESIGN.md 规定「用什么」，本文件规定「怎么排版才合格」。
> 参考 [HTML Anything](https://github.com/nexu-io/html-anything) 的做法：排版约束内置在模板骨骼里，而不是事后补救。

---

## 1. 基线网格（8px）

所有间距、内边距、组件高度取 **8 的倍数**；字号可以取 4 的倍数。

| 场景 | 取值 |
|---|---|
| 组件内边距 | 16 / 24 / 32 / 48 px |
| 组件间距 | 24 / 32 / 48 px |
| 页面左右边距 | 96 / 120 px |
| 分隔线与描边 | 1 / 2 px |

**为什么**：8 的倍数让不同人写的组件能拼在一起不出缝；也是 Retrofit 到 4K 时最稳的缩放基数。

## 2. 字体栈（CJK 优先）

**中文优先**：中文字体放在栈的前部，拉丁字体放后部。反过来会导致英文用中文字体渲染（字形丑、字距散）。

```
/* 无衬线（正文） */
"Helvetica Neue", Helvetica, Arial, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif

/* 衬线（标题/引言，仅 editorial-serif） */
Georgia, "Times New Roman", "Songti SC", "SimSun", "Noto Serif SC", serif

/* 展示（仅 8bit-orbit，已内嵌 woff2） */
"Tektur", "Chakra Petch", "Space Mono", "Noto Sans SC", "Microsoft YaHei", sans-serif
```

| 规则 | 说明 |
|---|---|
| 中西文混排加空格 | `30 分钟` 不写 `30分钟` |
| 中文行高 1.6–1.8 | 拉丁 1.2–1.4；中文必须放宽 |
| 数字用 tabular-nums | 滚动数字不抖 |
| 标题不加宽字距 | tracking 只用于拉丁 HUD 标签 |

## 3. 对比度（≥4.5:1）

正文与背景对比度**不低于 4.5:1**；大字（≥24px 或 19px 加粗）不低于 3:1。

| 组合 | 是否合格 |
|---|---|
| `#111` on `#fff` | ✅ 19.6:1 |
| `#fff` on `#0A0E27` | ✅ 18.9:1 |
| `#5EDCF4` on `#0A0E27` | ✅ 11.4:1 |
| `#F4D03F` on `#0A0E27` | ✅ 11.2:1 |
| `#F0A6CA` on `#0A0E27` | ✅ 8.7:1 |
| `rgba(255,255,255,.72)` on `#0F1B3D` | ✅ 约 9:1 |
| `rgba(255,255,255,.45)` on `#0F1B3D` | ❌ 约 4:1 —— 只用于装饰文字 |
| 白字 on `#F0A6CA` | ❌ 约 2.1:1 —— 禁用 |
| 深字 on `rgba(94,220,244,.14)` 底 | ❌ —— 高亮行必须实心底 |

**自检**：不确定时用 DevTools 的对比度检查，或把文字截图转灰度看是否还能读。

## 4. 网格列数

| 风格 | 列数 | 内容最大宽度 |
|---|---|---|
| swiss-modern | 12 列 | 1400 px |
| glass-neon | 12 列（隐式） | 1440 px |
| 8bit-orbit | 12 列（隐式） | 1520 px |
| editorial-serif | 不对称 5:7 或 4:8 | 1500 px |

**分栏规则**：两栏对半只用于「对比」；「主+辅」用 5:7 或 4:8，让主内容有视觉重量。

## 5. 字号阶梯（1920×1080 舞台）

一套幻灯片里**最多 6 级字号**。超过 6 级就是层级失控。

| 层级 | 8bit-orbit | glass-neon | swiss-modern | editorial-serif |
|---|---|---|---|---|
| L1 封面主标题 | 128 px | 4.9vw | 150 px | 120 px |
| L2 页面标题 | 64–72 px | 2.8vw | 72 px | 64 px |
| L3 大数字 | 44–84 px | 4vw | 96 px | 84 px |
| L4 组件标题 | 26–40 px | 1.28–1.42vw | 34 px | 34 px |
| L5 正文 | 19–23 px | 1.5vw | 26 px | 23–24 px |
| L6 标签/来源 | 12–13 px | .85vw | 16–18 px | 17–19 px |

## 6. 留白（负空间是设计的一部分）

| 指标 | 下限 |
|---|---|
| 页面内容占版面高度 | 60%–90%（低于 60% 太空，高于 90% 挤） |
| 标题与正文间距 | ≥ 24 px |
| 组件间距 | ≥ 24 px |
| 页面四边留白 | ≥ 88 px |
| 行长 | 中文 20–40 字/行（约 600–1000 px） |

## 7. 动效约束

| 项 | 规则 |
|---|---|
| 时长 | 入场 0.3–0.6s；hover 反馈 0.2–0.4s；氛围动画 ≥ 3s |
| 缓动 | 统一 `cubic-bezier(.22,.68,.3,1)` |
| 位移 | 入场 8–26px；**不要**超过 40px（会显得飘） |
| 只动一次 | 入场动画播完就停；不要无限循环抢注意力（氛围层除外） |
| reduced-motion | 必须响应 `prefers-reduced-motion`，全部关闭 |
| 一页动效 | 不超过 2 种 |

## 8. 禁用清单

| 禁用 | 原因 |
|---|---|
| 圆角 + 阴影同时用 | 两种语言打架 |
| 三种以上强调色 | 层级失控 |
| 渐变文字用在正文 | 可读性崩坏 |
| 全屏氛围层盖住正文 | 抢注意力（氛围层 z-index 必须在内容之下） |
| 纯装饰图标 | 没有信息量 |
| emoji 当项目符号 | 跨平台渲染不一致 |

## 9. 自检清单（交付前过一遍）

- [ ] 间距都是 8 的倍数
- [ ] 中文在字体栈前部
- [ ] 正文对比度 ≥4.5:1
- [ ] 字号 ≤6 级
- [ ] 内容占版面 60–90%
- [ ] 动效 ≤2 种/页，且尊重 reduced-motion
- [ ] 没有禁用清单里的项
