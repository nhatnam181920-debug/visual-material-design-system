# 设计系统总览 · 两套风格怎么选

> 本模块提供两套成熟、互补的 16:9 演示设计系统。它们共享同一套内容纪律与技术契约，差异只在视觉语言。

## 1. 快速对比

| | **Glass Neon** | **8-Bit Orbit** |
|---|---|---|
| 一句话 | 暗色玻璃拟态 + 霓虹渐变 | 像素复古未来 + CRT 屏幕感 |
| 底色 | 近黑（240 8% 4%） | 深空海军蓝（#0A0E27） |
| 强调色 | 红 `8 100% 59%` → 琥珀 → 青绿 | 青 `#5EDCF4` → 粉 → 黄 |
| 标题 | 轻字重 + 超大字号（h1 4.9vw / 600） | 重字重 + 像素阴影（128px / 900） |
| 质感 | 模糊光晕、玻璃卡片、细线网格 | 硬边阴影、L 形角标、扫描线/噪点/星野 |
| 字体 | 系统字体（零依赖） | Tektur / Chakra Petch / Space Mono + 系统中文字体 |
| 画布 | 视口 vw/vh（16:9 屏幕等比） | 固定 1920×1080 整体缩放 |
| 页数建议 | 8–12 页 | 10–14 页 |
| 适合 | 路演、产品介绍、数据汇报、商业计划 | 黑客松、产品发布、技术分享 |
| 不适合 | 需要「像素/屏幕」记忆点的场合 | 保守正式场合（政策/法务/医疗） |

### 另两套（同契约，零依赖）

| | **Swiss Modern** | **Editorial Serif** |
|---|---|---|
| 一句话 | 瑞士国际主义：一种字体、黑白红、严格网格 | 杂志编辑风：衬线标题 + 无衬线正文、赭红强调 |
| 底色 / 强调 | 白底 / 瑞士红 `#E4032E` | 暖纸白 `#F0EFE9` / 赭红 `#8C2F1E` |
| 字体 | Helvetica 系（系统） | Georgia 衬线（系统）+ Helvetica 正文 |
| 装饰 | 只有线与数字 | 只有细线与字号对比 |
| 动效 | 几乎为零 | 几乎为零 |
| 适合 | 融资路演、正式商务汇报 | 品牌故事、内容/IP 介绍 |
| 不适合 | 需要氛围感的场合 | 堆数据的场合 |

## 2. 选择口诀

- 要「**高级、克制、可信**」→ Glass Neon
- 要「**技术、能量、记忆点**」→ 8-Bit Orbit
- 评委是投资人/客户/业务方 → Glass Neon
- 评委是工程师/黑客松/技术评审 → 8-Bit Orbit

## 3. 通用规则（两套都适用）

### 内容纪律
1. **结论先行**：第 2 页就给结果或核心数字，不要铺垫三页
2. **一页一件事**：标题讲结论，组件给证据，底部一句金句
3. **数字有出处**：来源写进 `.src`/`.footline`；查不到来源就不写
4. **边界诚实**：不确定的标「假设」；不承诺效果；不虚构案例
5. **密度控制**：单页组件 ≤ 3 组；内容占版面 60–90%，留白不空

### 中文排版
- 标题不加宽字距（拉丁才用 tracking）；不做大写
- 中英之间留空格（盘古之白）：`30 分钟` 不写 `30分钟`
- 行高比拉丁稿放宽 0.15（正文 1.6–1.8）
- 标点用全角：，。：；！？「」（）——破折号用 ——
- 标题末尾不加句号

### 技术契约
- 16:9 画布；键盘 ← → 空格 / PageUp/PageDown / Home/End 翻页；触摸左右滑
- 离线可播：字体/图片/视频内嵌（`bundle-assets.py`）
- 可打印：Ctrl+P 每页一张
- 每页 `aria-label`；`prefers-reduced-motion` 关闭动效

### 图片与视频
- 图片位用模板里的 `.slot` / `.img-slot`，放 `<img>` 即替换
- 视频只放 10–20 秒片段（静音循环），面板上标注「片段」
- 单文件体积 ≤ 4MB；更大就拆「deck + 素材包」

## 4. 验收

两套风格共用同一套验收脚本与标准：`scripts/qa-deck.cjs` + [docs/验收标准.md](docs/验收标准.md)。
通过标准（自动检查）：
- 元素级溢出 0 处
- 每页内容垂直平衡（ok/filled）
- 字体与媒体全部加载
- 零相对外链、零 JS 异常

## 5. 演进规则

- 新增风格：在 `styles/` 下建目录（DESIGN.md + template.html + `_base.css`），并在本文件第 1 节表格补一行
- 修改令牌：只改 `:root`，不要散落硬编码颜色
- 组件升级：先改 `template.html` 与 `_base.css`，再回填 DESIGN.md 的组件表
