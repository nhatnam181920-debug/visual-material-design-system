# Glass Neon · 设计系统

> 暗色玻璃拟态 + 霓虹渐变。深色底、模糊光晕、网格线、颗粒，大字号轻字重标题，玻璃卡片，红色高亮做强调。
> 适用范围：路演、产品介绍、数据汇报、商业计划展示。中文优先。

## 1. 设计令牌（HSL 体系）

所有颜色用 `hsl()` 分量变量，改主题只改 `:root`：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` / `--bg-2` | `240 8% 4%` / `240 8% 6%` | 页面底色（近黑带蓝紫） |
| `--fg` | `40 20% 97%` | 主文字（暖白） |
| `--fg-2` / `--fg-3` | `35 10% 72%` / `35 8% 52%` | 次级文字 / 辅助文字 |
| `--hot` / `--hot-2` | `8 100% 59%` / `8 100% 70%` | 强调红（主强调色） |
| `--amber` | `38 100% 58%` | 琥珀（次强调，用于数据/平台色） |
| `--teal` / `--teal-2` | `188 78% 55%` / `188 70% 74%` | 青绿（第三色，用于「完成/技术」语义） |
| `--line` / `--line-2` | `0 0% 100% / .09` / `.16` | 分隔线 / 强分隔线 |
| `--glass` | `0 0% 100% / .035` | 玻璃填充 |
| `--ease` | `cubic-bezier(.22,.68,.3,1)` | 统一缓动 |
| `--pad` | `5.5vh 8vw` | 页面内边距 |

**换主题**：只改 `--hot`/`--amber`/`--teal` 三个色相值，其余不动。

## 2. 字体与字号

全部使用**系统字体**（离线可用、零字体文件）：

```
font-family:"PingFang SC","HarmonyOS Sans SC","Microsoft YaHei","Hiragino Sans GB",system-ui,sans-serif;
```

字号用 `vw`（16:9 屏幕上等比缩放）：

| 角色 | 类名 | 字号 | 字重 | 说明 |
|---|---|---|---|---|
| 封面主标题 | `h1` | 4.9vw | 600 | 负字距 -0.025em；`<em>` 变红加粗 800 |
| 页面标题 | `h2` | 2.8vw | 600 | 负字距 -0.018em；最大 26ch |
| 卡片标题 | `.card b` / `.step b` | 1.28–1.42vw | 700 | |
| 正文 | `p,li,td,th` | 1.5vw | 400 | 行高 1.62 |
| 导语 | `.lead` | 1.78vw | 400 | 最大 52ch；`b` 提亮，`.hl` 变红 |
| 小字/来源 | `.src` | .85vw | 400 | 来源、口径、免责 |
| 眉标 | `.kicker` | 1vw | 600 | 大写 + 0.3em 字距 + 前方 2.4vw 横线 |
| 数字 | `.stat .n` | 4vw | 600 | tabular-nums；`small` 变红 |

**规则**：标题永远「轻字重 + 大字号」，不要用 800 做整句；强调只给关键词（`<em>`）。

## 3. 氛围层（固定装饰，不可省）

三个 `position:fixed` 层，任何页面都保留：

1. `.atmos` — 三团 `blur(90px)` 的径向光晕（红/琥珀/青），30–42s 缓慢漂移
2. `.gridlines` — 12 格竖线 + 8 格横线（`--line` 9% 白），营造版面网格感
3. `.grain` — SVG 噪点，`opacity:.055`，`mix-blend-mode:overlay`

**不要**给单个元素加阴影或模糊发光——发光只来自氛围层与红色元素本身。

## 5. 布局规则

- 每页一个信息点；标题 + 一组组件 + 可选 `.yield` + 可选 `.src`
- 页面用 `display:flex; flex-direction:column; justify-content:center` 垂直居中
- 数据必须带来源（`.src`），没来源的数字不要出现
- 页数 8–12 页为宜；单页组件不超过 3 组

## 6. 动效

- 翻页：`sIn` 0.6s（位移 + 缩放 + 模糊消散）
- 内容入场：`.slide.active > *` 依次 `rise`（0.68s，每项延迟 0.06–0.09s）
- 数字：`data-count` 属性 + requestAnimationFrame 计数（模板已带）
- 条形：`data-w` 宽度动画
- 所有动效在 `prefers-reduced-motion` 或打印时关闭（CSS 已处理 print）

## 7. 打印

模板自带 `@media print`：自动**反转浅底**（白底 + 深色字 + 红色强调保留），每页一页，隐藏氛围层、导航、幽灵序号。直接 Ctrl+P 导出 PDF 即为可用静态稿。

## 8. Do / Don't

**Do**
- 每页只讲一件事，标题用 `<em>` 标出唯一关键词
- 数据行放 4 个以内；超过 4 个改成卡片
- 强调色的顺序：红（主）> 琥珀（次）> 青绿（第三）
- 每组组件之间有 2.2–3.4vh 间距，保持呼吸

**Don't**
- 不要给单个卡片加 `box-shadow` 光晕（发光只来自氛围层）
- 不要把正文做成大写或加宽字距（那是 `.kicker` 的专属）
- 不要用超过 3 种强调色
- 不要在深色底上用纯白正文（用 `--fg-2`）
- 不要删掉 `.atmos` / `.gridlines` / `.grain`（氛围层是这个系统的身份）
