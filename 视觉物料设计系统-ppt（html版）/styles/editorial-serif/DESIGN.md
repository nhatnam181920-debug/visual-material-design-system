# Editorial Serif · 设计系统

> 杂志编辑风：衬线大标题 + 无衬线正文、暗底纸白、严格的竖排节奏、极少的强调色。
> 设计语言参考 [reveal.js](https://github.com/hakimel/reveal.js) `serif`/`black` 主题的公开实现（Palatino 衬线 + 纸白底），按本仓库「单文件 / 零依赖 / 可 QA」契约重写。
> 适用范围：品牌故事路演、内容/IP 介绍、需要「安静、有分量」的正式场合。**适合讲故事，不适合堆数据**。

## 1. 设计令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink` | `#1A1A1A` | 纸面主文字 |
| `--paper` | `#F0EFE9` | 页面底（暖纸白，非纯白） |
| `--paper-2` | `#E7E5DC` | 次纸面（引用块/表格纹） |
| `--dark` | `#141414` | 暗面（转场/结尾） |
| `--accent` | `#8C2F1E` | 唯一强调色（赭红，只用于一处） |
| `--rule` | `rgba(26,26,26,.22)` | 分隔线 |
| `--serif` | `Georgia, "Times New Roman", "Songti SC", "SimSun", "Noto Serif SC", serif` | 标题字体 |
| `--sans` | `"Helvetica Neue", Arial, "PingFang SC", "Microsoft YaHei", sans-serif` | 正文字体 |

## 2. 字体与字号

**衬线只做标题与引言，正文一律无衬线**——这是编辑风的核心纪律。

| 角色 | 字体 | 字号（1920 舞台） | 字重 |
|---|---|---|---|
| 封面主标题 | 衬线 | 120px | 400（衬线不加粗，靠字号） |
| 页面标题 | 衬线 | 64px | 400 |
| 引言/大字 | 衬线 | 72px | 400 |
| 正文 | 无衬线 | 26px | 400 |
| 说明文字 | 无衬线 | 22px | 400 |
| 标签（HUD） | 无衬线 | 17px | 700 + 0.24em 字距大写 |
| 数据 | 衬线 | 84px | 400，tabular-nums |

## 3. 排版节奏

- **竖排优先**：每页内容自上而下一条线，最多两组并排（`2fr 3fr` 不对称分栏）
- **首行缩进式引文**：引用块用左侧 2px 赭红线 + 纸白加深底
- **页码在右下角**，小号衬线斜体（`03`），不用胶囊
- **章与章之间用暗面转场**：一页暗底大字，像杂志的跨页
- **禁止**：圆角、阴影、渐变、氛围层、发光。装饰只有**细线、字号对比、留白**

## 4. 组件清单

| 组件 | 类名 | 用法 |
|---|---|---|
| 页眉 | `.ed-head` | 左：章节名（小字大字距）；右：日期/品牌 |
| 页码 | `.ed-page` | 右下角衬线斜体数字 |
| 标题 | `.ed-title` | 衬线 64px，行高 1.25 |
| 引言 | `.ed-quote` | 衬线 72px + 左 2px 赭红线 |
| 两栏 | `.ed-2col` | 不对称 5fr / 7fr |
| 数据组 | `.ed-stats` | 2–3 个衬线大数字，横排，细线分隔 |
| 列表 | `.ed-list` | 无序号圆点，用「—」破折号引导 |
| 表格 | `.ed-table` | 细线，表头小字大字距 |
| 图片位 | `.ed-figure` | 纸白加深底 + 图注（衬线斜体小字） |
| 暗面转场 | `.slide.dark` | 整页暗底，衬线大白字 |

## 5. 动效（几乎为零）

- 翻页：0.4s 淡入 + 8px 上移
- **没有**数字滚动（衬线数据的庄重感来自静态）
- 没有氛围层、星野、辉光——「安静」是这个风格的身份

## 6. Do / Don't

**Do**
- 每页一段文字讲一件事，标题即结论
- 强调色（赭红）每页最多出现一次
- 用不对称分栏制造编辑感（5:7 或 4:8）
- 引用块承载「客户原话 / 用户声音」

**Don't**
- 不要给衬线标题加粗（衬线的分量来自字号，加粗就廉价了）
- 不要用三种以上字号
- 不要堆数据图表（这是讲故事的系统，数据用 2–3 个就够）
- 不要用 emoji 或图标
