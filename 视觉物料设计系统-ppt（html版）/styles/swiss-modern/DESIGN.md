# Swiss Modern · 设计系统

> 瑞士国际主义：Helvetica 网格、红白蓝三色、超大字号、严格左对齐、数学网格。
> 设计语言参考 [reveal.js](https://github.com/hakimel/reveal.js) `white`/`serif` 主题与 Slidev 默认主题的公开实现，按本仓库「单文件 / 零依赖 / 可 QA」契约重写。
> 适用范围：融资路演、产品发布、正式商务汇报。**最稳、最不会错的选择**。

## 1. 设计令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink` | `#111111` | 主文字（近黑） |
| `--paper` | `#FFFFFF` | 页面底 |
| `--red` | `#E4032E` | 唯一强调色（瑞士红） |
| `--blue` | `#0B4EA2` | 次强调（仅用于数据/链接） |
| `--rule` | `#111111` | 分隔线（1px 或 2px，纯黑） |
| `--grid` | `rgba(17,17,17,.045)` | 背景网格线 |
| `--sans` | `Helvetica Neue, Helvetica, Arial, "PingFang SC", "Microsoft YaHei", sans-serif` | 全场唯一字体族 |

**色彩纪律**：黑白红三色，蓝只用于数字高亮。**没有第三种字重以上的强调手段**。

## 2. 字体与字号

全场一种字体族（Helvetica 系），靠**字号、字重、位置**建立层级——这正是瑞士风格的核心。

| 角色 | 字号（1920 舞台） | 字重 | 说明 |
|---|---|---|---|
| 封面主标题 | 150px | 700 | 左对齐，可两行，负字距 -0.02em |
| 页面标题 | 72px | 700 | 顶部 2px 黑线之上 |
| 副标题 | 34px | 400 | 灰色 `#555` |
| 正文 | 26px | 400 | 行高 1.55 |
| 数据 | 96px | 700 | tabular-nums；红或黑 |
| 标签（HUD） | 18px | 700 | 大写 + 0.2em 字距 |
| 表格 | 24px | 400 | 1px 黑线分隔 |

## 3. 网格与对齐（本系统的灵魂）

- **12 列网格**：内容区 max-width 1400px，左右边距 96px
- **严格左对齐**：所有文本块左对齐到网格线；只有封面与结尾页可居中
- **顶部与底部粗线**：每页顶部 2px 黑线（带页码/标签），底部 1px 细线（带来源）
- **禁止**：圆角、阴影、渐变、装饰图形、氛围层。装饰只能是**线与数字**

## 4. 组件清单

| 组件 | 类名 | 用法 |
|---|---|---|
| 页眉 | `.swiss-head` | 左：章节标签；右：页码（`01 / 12`），上边框 2px 黑 |
| 页脚 | `.swiss-foot` | 左：来源；右：品牌名，上边框 1px 黑 |
| 数据组 | `.swiss-stats` | 2–4 个大数字，数字间竖线分隔 |
| 两栏 | `.swiss-2col` | 严格对半，中间竖线 |
| 三栏 | `.swiss-3col` | 三等分，中间竖线 |
| 编号列表 | `.swiss-list` | `01 02 03` 红色序号 + 黑标题 |
| 表格 | `.swiss-table` | 1px 黑线，表头加粗 |
| 大字引言 | `.swiss-quote` | 80px 左对齐，可含红色强调 |
| 红点强调 | `.swiss-mark` | 行内红色粗体（唯一的高亮手段） |
| 全屏色块 | `.swiss-band` | 整页红底白字（仅用于转场/结尾，一页一次） |

## 5. 动效（极少）

- 翻页：0.3s 纯淡入，无位移无缩放
- 数据：可滚动（`data-count-to`），无其他动效
- **没有**氛围层、星野、辉光、粒子——瑞士风格的「高级」来自留白与秩序

## 6. Do / Don't

**Do**
- 每页内容不超过网格的 60%（留白是设计的一部分）
- 序号统一用 `01` `02` 补零格式
- 数字与单位分栏（数字 96px、单位 26px 基线对齐）
- 一页只用一个强调色元素（一个红块或一句红字）

**Don't**
- 不要加圆角 / 阴影 / 渐变 / 玻璃拟态
- 不要用超过两种字重
- 不要把文本居中（除封面/结尾）
- 不要用图标或 emoji 替代排版层级
