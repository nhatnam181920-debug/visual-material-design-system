# 字体与资源

## 各风格用什么字体

| 风格 | 字体方案 | 是否内嵌 |
|---|---|---|
| **glass-neon** | 系统字体：`PingFang SC` / `HarmonyOS Sans SC` / `Microsoft YaHei` / `Hiragino Sans GB` → `system-ui` | 不需要（零字体文件） |
| **8bit-orbit** | 拉丁：`Tektur`（展示）+ `Chakra Petch`（正文）+ `Space Mono`（HUD）；中文：系统黑体 900 | 拉丁字体以 data URI 内嵌在模板里（约 38KB 原始 / 50KB base64） |

### 为什么 8bit-orbit 的中文用系统字体

像素风的「分量」主要来自：900 字重的中文黑体 + 硬边像素阴影 + 大气层（扫描线/噪点/星野）。思源黑体/微软雅黑的 900 字重已经能承载，不需要额外的中文像素字体（中文市场也几乎没有可用的像素黑体）。

如需跨机器完全一致：把 `styles/8bit-orbit/fonts/NotoSansSC-subset.woff2`（演示文案子集）替换为你自己文案的字形子集，再用 `bundle-assets.py` 内嵌。生成子集的命令：

```bash
python -c "from fontTools import subset; ..."   # 或参考仓库外做法：fontTools subset NotoSerifSC-VF.ttf --text-file=文案.txt --flavor=woff2
```

## 资源内嵌规则

| 资源 | 处理 | 工具 |
|---|---|---|
| 字体 woff2 | data URI | `bundle-assets.py` |
| 图片 png/jpg/webp | data URI（建议先压到 ≤ 300KB/张） | `bundle-assets.py` |
| 视频 mp4 | data URI（只放 10–20 秒片段，≤ 1.5MB） | `bundle-assets.py` |
| 外部 CDN / Google Fonts | **禁止**（离线要求） | — |

## 体积参考

| 内容 | 体积 |
|---|---|
| 模板（无媒体） | 26–88 KB |
| 加 3 张截图 | +300–900 KB |
| 加 20 秒 720p 视频片段 | +1.6 MB（base64） |
| 单文件上限建议 | ≤ 4 MB（更大就拆成「deck + 素材包」两个文件） |

## 字体许可

- Tektur / Chakra Petch / Space Mono：Google Fonts（OFL），可自由内嵌；保留字体名与许可声明。
- 系统字体（PingFang / YaHei / HarmonyOS）：不随文件分发，依赖系统。
