# 验收标准

> 任何交付前必须全部通过。`scripts/qa-deck.cjs` 已自动检查 1–7 项；8–10 项需人工目检。

## 自动检查（qa-deck.cjs，零配置）

| # | 项 | 通过标准 | 失败处理 |
|---|---|---|---|
| 1 | 页数与舞台 | `.slide` 数量 ≥ 3；stage 为 1920×1080 或 fluid 视口 | 检查 `.slide` 类与舞台结构 |
| 2 | 元素级溢出 | 内容元素 0 处越界（装饰层除外） | 缩小字号/图片或改布局 |
| 3 | 垂直平衡 | 每页 `ok(上/下)` 或 `filled(≥85%)`；`tight(≥96%)` 只告警 | 加 `.content-mid` 或放大组件；过挤则删内容 |
| 4 | 键盘翻页 | → ← End Home 真实按键均能切页 | 检查翻页脚本（键盘事件监听） |
| 5 | 占位文案 | 0 处模板残留（`主标题第一行`、`步骤一`…） | 改成真实内容（模板本身报错属预期） |
| 6 | 字体/媒体 | 字体 loaded；`img` 完整、`video` readyState≥2 | 检查 data URI |
| 7 | 外链与异常 | 0 个相对外部资源；0 个未捕获 JS 异常 | 跑 `bundle-assets.py`；修脚本 |

## 人工目检（必做）

| # | 项 | 检查方法 |
|---|---|---|
| 8 | 设计一致性 | 通读 DESIGN.md 的 Do/Don't；检查是否混入其他风格元素（如 glass-neon 里出现像素阴影） |
| 9 | 内容质量 | 第 2 页是否给出结果；每页是否只有一个信息点；数字是否有来源；是否有虚构案例/效果承诺 |
| 10 | 中文排版 | 标题未加宽字距/未大写；中英之间留空格；行高比设计稿宽松；无孤字成行（最后一行 1–2 字） |

## 打印检查

- glass-neon：Ctrl+P 应自动反转浅底（白底深字），每页一页
- 8bit-orbit：`@page 1920px 1080px`，每页一页；暗色页打印偏黑属正常（该风格以屏幕为主，静态备份用 `make-pdf.py` 更稳）
