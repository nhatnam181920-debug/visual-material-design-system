# 验收标准

> 任何交付前必须全部通过。`scripts/qa-deck.cjs` 已自动检查 1–7 项；8–10 项需人工目检。

## 自动检查（qa-deck.cjs）

| # | 项 | 通过标准 | 失败处理 |
|---|---|---|---|
| 1 | 页数与舞台 | `.slide` 数量 ≥ 3；stage 为 1920×1080 或 fluid 视口 | 检查 `.slide` 类与舞台结构 |
| 2 | 元素级溢出 | 内容元素 0 处越界（装饰层除外） | 缩小字号/图片或改布局 |
| 3 | 垂直平衡 | 每页内容 `ok(上/下)` 或 `filled(≥85%)` | 加 `.content-mid` 或放大组件 |
| 4 | 字体 | 8bit-orbit 三套拉丁字体全部 loaded；glass-neon 用系统字体 | 检查字体 data URI |
| 5 | 媒体 | 所有 `<img>` complete 且 naturalWidth>0；`<video>` readyState≥2 | 检查 data URI 或路径 |
| 6 | 外链 | 0 个相对外部资源（`data:` 除外） | 跑 `bundle-assets.py` |
| 7 | JS 异常 | 0 个未捕获异常 | 修复脚本 |

## 人工目检（必做）

| # | 项 | 检查方法 |
|---|---|---|
| 8 | 设计一致性 | 通读 DESIGN.md 的 Do/Don't；检查是否混入其他风格的元素（如 glass-neon 里出现像素阴影） |
| 9 | 内容质量 | 第 2 页是否给出结果；每页是否只有一个信息点；数字是否有来源；是否有虚构案例/效果承诺 |
| 10 | 中文排版 | 标题未加宽字距/未大写；中英之间留空格；行高比设计稿宽松；无孤字成行（最后一行 1–2 字） |

## 打印检查

- glass-neon：Ctrl+P 应自动反转浅底（白底深字），每页一页
- 8bit-orbit：`@page 1920px 1080px`，每页一页；暗色页打印偏黑属正常（该风格以屏幕为主，静态备份用 `make-pdf.py` 更稳）
